# Phỏng vấn stakeholder (Elicitation)

> **Trạng thái:** chưa có phỏng vấn nào được thực hiện. Theo process, **con người** phỏng vấn stakeholder; agent chỉ chuẩn bị câu hỏi (vai trò AI-as-client) và tổng hợp sau đó. Agent không tạo biên bản phỏng vấn giả.

| File | Nội dung |
|---|---|
| [elicitation-question-set.md](elicitation-question-set.md) | Bộ câu hỏi theo `BRD_Elicitation_Prompt_IEEE_standard.md`, nhắm vào các câu hỏi mở của BRD |
| [interview-template.md](interview-template.md) | Mẫu biên bản cho mỗi buổi phỏng vấn |

Đặt tên biên bản: `YYYY-MM-DD-<stk-id>-<ten>.md`, ví dụ `2026-11-03-STK-002-linh.md`.
Sau mỗi buổi phỏng vấn: cập nhật BRD (đổi `[Unverified]` → có nguồn), đóng OQ tương ứng, ghi vào lịch sử phiên bản BRD.
